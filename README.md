# 茶蛋品牌 Skill

为茶蛋（ChaDan Land）制作 PPT、HTML、PDF、海报和其他视觉物料时使用的品牌 Skill。它内置官方 Logo、寒蝉有机体和思源黑体，并要求首次交付即正确加载品牌字体。

## 给使用者：一句话安装

在 **Codex** 或 **Claude Code** 的对话中，发送下面这句话：

> 请安装这个 Skill：`https://github.com/LynxCisme/chadan-brand-design/tree/main/skills/chadan-brand`

安装完成后，开始一个新对话，再说：

> 请使用茶蛋品牌制作一份 HTML 演示文稿。

不需要注册 GitHub；安装时工具可能会请求一次写入本地 Skills 目录的授权，选择允许即可。

## 内容

- `skills/chadan-brand/SKILL.md`：完整品牌规则
- `assets/fonts/`：寒蝉有机体与思源黑体
- `assets/logos/`：官方彩色、黑色、白色 Logo
- `assets/graphics/`：官方辅助图形

## 资源使用

品牌资产用于茶蛋及已获授权项目。不得重绘、变形、转售或冒用 Logo；请遵守包内 `ASSET-NOTICE.md` 的说明。
